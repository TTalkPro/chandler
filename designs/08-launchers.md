# 08 — 启动器生成

> 状态: 设计中

## 1. 一句话目标

生成三种形态(app / install / pack)的启动器,解决 bootstrap paradox,使 `(chandler setup)` 在 library-directories 接管前能被找到。

## 2. 三态对照表

| 模式 | 启动器位置 | runtime 来源 | library-directories 初始值 |
|------|----------|------------|---------------------------|
| **dev** | (无独立启动器,`chandler run` 子进程) | 系统 | `resolved-libdirs`(实时算) |
| **install** | `~/.local/bin/<app>` (POSIX) / `%LOCALAPPDATA%\chez\bin\<app>.ps1` (Windows) | 系统 skiff/scheme | chandler-runtime prefix(让 setup 可见) |
| **pack** | `<pack>/bin/<app>` (POSIX) / `<pack>/bin/<app>.ps1` (Windows) | bundled `<pack>/chandler-runtime/` | bundled `<pack>/chandler-runtime/`(D5 决策) |

## 3. POSIX 启动器模板

### 3.1 install 模式

```sh
#!/bin/sh
# <name> launcher — generated by chandler install; do not edit.
# Uses the local Scheme runtime (skiff preferred); mounts the install prefix.
PREFIX="{{libdir}}"
MT="{{mt}}"
RUNNER="$PREFIX/.chandler/{{name}}/run.sps"

# Runtime discovery: CHANDLER_RUNTIME > PATH search (skiff > scheme > chez)
case "${CHANDLER_RUNTIME:-}" in
  skiff) _rt="${CHANDLER_SKIFF:-skiff}" ;;
  chez)  _rt="${CHANDLER_SCHEME:-scheme}" ;;
  "")
    for _c in skiff scheme chez; do
      command -v "$_c" >/dev/null 2>&1 && { _rt="$_c"; break; }
    done ;;
  *) echo "{{name}}: invalid CHANDLER_RUNTIME (want: skiff|chez)" 1>&2; exit 64 ;;
esac

[ -z "$_rt" ] && { echo "{{name}}: no Scheme runtime found (install skiff or Chez Scheme)" 1>&2; exit 127; }
[ ! -f "$RUNNER" ] && { echo "{{name}}: install broken — $RUNNER missing (reinstall with chandler install)" 1>&2; exit 70; }

# --libdirs 指向 chandler-runtime prefix,使 (chandler setup) 在接管前可见
exec "$_rt" -q --libdirs "$PREFIX::$PREFIX/$MT" --program "$RUNNER" "$@"
```

### 3.2 pack 模式

```sh
#!/bin/sh
# <name> launcher — generated by chandler pack; do not edit.
# Uses the bundled runtime; mounts the pack prefix.
HERE="$(dirname "$(readlink -f "$0")")"
PACK_ROOT="$(dirname "$HERE")"
MT="{{mt}}"
RUNTIME="$PACK_ROOT/chandler-runtime"
RUNNER="$PACK_ROOT/{{name}}/{{version}}/.chandler/run.sps"

# Runtime discovery: CHANDLER_RUNTIME > bundled > PATH search
case "${CHANDLER_RUNTIME:-}" in
  skiff) _rt="${CHANDLER_SKIFF:-skiff}" ;;
  chez)  _rt="${CHANDLER_SCHEME:-scheme}" ;;
  "")
    # Try bundled first
    if [ -x "$RUNTIME/$MT/skiff" ]; then
      _rt="$RUNTIME/$MT/skiff"
    elif [ -x "$RUNTIME/$MT/scheme" ]; then
      _rt="$RUNTIME/$MT/scheme"
    else
      # Fall back to PATH
      for _c in skiff scheme chez; do
        command -v "$_c" >/dev/null 2>&1 && { _rt="$_c"; break; }
      done
    fi ;;
  *) echo "{{name}}: invalid CHANDLER_RUNTIME (want: skiff|chez)" 1>&2; exit 64 ;;
esac

[ -z "$_rt" ] && { echo "{{name}}: no Scheme runtime found" 1>&2; exit 127; }
[ ! -f "$RUNNER" ] && { echo "{{name}}: pack broken — $RUNNER missing" 1>&2; exit 70; }

# --libdirs 指向 bundled chandler-runtime,使 (chandler setup) 在接管前可见
exec "$_rt" -q --libdirs "$RUNTIME/src::$RUNTIME/$MT" --program "$RUNNER" "$@"
```

### 3.3 关键差异

| 参数 | install | pack |
|------|---------|------|
| `--libdirs` | `$PREFIX/src::$PREFIX/$MT` | `$RUNTIME/src::$RUNTIME/$MT` |
| runtime 缺省 | PATH 发现 | bundled runtime |

## 4. Windows PowerShell 启动器模板

### 4.1 install 模式

```powershell
#!/usr/bin/env pwsh
# <name> launcher — generated by chandler install; do not edit.
$ErrorActionPreference = 'Continue'
$AppArgs = $args
$Prefix = '{{libdir}}'
$Mt = '{{mt}}'
$Runner = "$Prefix/.chandler/{{name}}/run.sps"
$Sep = [System.IO.Path]::PathSeparator

# Runtime discovery: CHANDLER_RUNTIME > PATH search (skiff > scheme > chez)
switch ($env:CHANDLER_RUNTIME) {
  'skiff' { $rt = if ($env:CHANDLER_SKIFF) { $env:CHANDLER_SKIFF } else { 'skiff' } }
  'chez'  { $rt = if ($env:CHANDLER_SCHEME) { $env:CHANDLER_SCHEME } else { 'scheme' } }
  ''      { foreach ($c in @('skiff','scheme','chez')) { if (Get-Command $c -ErrorAction SilentlyContinue) { $rt = $c; break } } }
  $null   { foreach ($c in @('skiff','scheme','chez')) { if (Get-Command $c -ErrorAction SilentlyContinue) { $rt = $c; break } } }
  default { [Console]::Error.WriteLine("{{name}}: invalid CHANDLER_RUNTIME (want: skiff|chez)"); exit 64 }
}

if (-not $rt) { [Console]::Error.WriteLine("{{name}}: no Scheme runtime found"); exit 127 }
if (-not (Test-Path -LiteralPath $Runner)) { [Console]::Error.WriteLine("{{name}}: install broken — $Runner missing"); exit 70 }

# --libdirs 格式:Windows 双分号表示 (src . obj) 对
& $rt -q --libdirs "$Prefix$Sep$Sep$Prefix/$Mt" --program $Runner @AppArgs
exit $LASTEXITCODE
```

### 4.2 pack 模式

```powershell
#!/usr/bin/env pwsh
# <name> launcher — generated by chandler pack; do not edit.
$ErrorActionPreference = 'Continue'
$AppArgs = $args
$Here = Split-Path -Parent $MyInvocation.MyCommand.Path
$PackRoot = Split-Path -Parent $Here
$Mt = '{{mt}}'
$Runtime = Join-Path $PackRoot "chandler-runtime"
$Runner = "$PackRoot/{{name}}/{{version}}/.chandler/run.sps"
$Sep = [System.IO.Path]::PathSeparator

# Runtime discovery: CHANDLER_RUNTIME > bundled > PATH search
switch ($env:CHANDLER_RUNTIME) {
  'skiff' { $rt = if ($env:CHANDLER_SKIFF) { $env:CHANDLER_SKIFF } else { 'skiff' } }
  'chez'  { $rt = if ($env:CHANDLER_SCHEME) { $env:CHANDLER_SCHEME } else { 'scheme' } }
  ''      {
    # Try bundled first
    $BundledRt = Join-Path $Runtime "$Mt/skiff.exe"
    if (Test-Path $BundledRt) { $rt = $BundledRt } else {
      $BundledRt = Join-Path $Runtime "$Mt/scheme.exe"
      if (Test-Path $BundledRt) { $rt = $BundledRt } else {
        foreach ($c in @('skiff','scheme','chez')) { if (Get-Command $c -ErrorAction SilentlyContinue) { $rt = $c; break } }
      }
    }
  }
  $null   {
    $BundledRt = Join-Path $Runtime "$Mt/skiff.exe"
    if (Test-Path $BundledRt) { $rt = $BundledRt } else {
      foreach ($c in @('skiff','scheme','chez')) { if (Get-Command $c -ErrorAction SilentlyContinue) { $rt = $c; break } }
    }
  }
  default { [Console]::Error.WriteLine("{{name}}: invalid CHANDLER_RUNTIME (want: skiff|chez)"); exit 64 }
}

if (-not $rt) { [Console]::Error.WriteLine("{{name}}: no Scheme runtime found"); exit 127 }
if (-not (Test-Path -LiteralPath $Runner)) { [Console]::Error.WriteLine("{{name}}: pack broken — $Runner missing"); exit 70 }

# --libdirs 指向 bundled chandler-runtime
& $rt -q --libdirs "$Runtime/src$Sep$Sep$Runtime/$Mt" --program $Runner @AppArgs
exit $LASTEXITCODE
```

## 5. runtime 发现逻辑

### 5.1 优先级

```
CHANDLER_RUNTIME=skiff|chez  (显式覆盖)
         ↓
pack 模式: bundled <pack>/chandler-runtime/$MT/
install 模式: PATH 发现 (skiff > scheme > chez)
         ↓
CHANDLER_SKIFF=<path>  (指定具体可执行文件)
CHANDLER_SCHEME=<path>
```

### 5.2 找不到时的退出码

| 退出码 | 含义 |
|--------|------|
| 64 | `CHANDLER_RUNTIME` 非法值(不是 skiff/chez) |
| 127 | 找不到任何可用 runtime |

### 5.3 显式覆盖语义

- `CHANDLER_SKIFF=/opt/bin/skiff`:只尝试该路径,不存在则 127
- `CHANDLER_RUNTIME=chez`:只尝试 chez,不使用 skiff
- **不静默回退**:显式指定意味着用户要精确控制,找不到即失败

## 6. Bootstrap Paradox 解决

### 6.1 完整流程

```
┌─────────────────────────────────────────────────────────────────────┐
│ 1. launcher exec runtime --libdirs <chandler-runtime-src>::<mt>     │
│                          --program run.sps                           │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 2. runtime 加载 run.sps                                               │
│    (car (command-line)) = "/path/to/run.sps"                         │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 3. run.sps 执行 (import (chandler setup))                           │
│    (chandler setup) 位于 chandler-runtime/src/chandler/setup.ss     │
│    因 --libdirs 已指向 chandler-runtime,可以被找到                    │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 4. (chandler setup) 执行四步流程(详见 07):                          │
│    a. 从 run.sps 路径反推 manifest.lock 位置                         │
│    b. 读取 manifest.lock                                             │
│    c. 重写 library-directories 为 per-package-version 闭包           │
│    d. 控制交回 run.sps                                                │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 5. run.sps 继续执行 (import (myapp main))                            │
│    myapp 及其 dep 通过新的 library-directories 解析                   │
└─────────────────────────────────────────────────────────────────────┘
```

### 6.2 install vs pack 差异

| 阶段 | install | pack |
|------|---------|------|
| chandler-runtime 来源 | 系统 `~/.local/share/chez/` | bundled `<pack>/chandler-runtime/` |
| `--libdirs` 初始值 | `$CHANDLER_HOME/src::$CHANDLER_HOME/$MT` | `$RUNTIME/src::$RUNTIME/$MT` |
| manifest.lock 位置 | `<prefix>/.chandler/<name>/manifest.lock` | `<pack-root>/<name>/<version>/.chandler/manifest.lock` |

## 7. 旗标透传

所有运行时相关环境变量在 install 和 pack 模式均生效:

| 变量 | 作用 |
|------|------|
| `CHANDLER_RUNTIME` | 强制使用 skiff 或 chez |
| `CHANDLER_SKIFF` | skiff 可执行文件路径 |
| `CHANDLER_SCHEME` | chez/scheme 可执行文件路径 |

## 8. 退出码语义

沿用 sysexits.h 约定:

| 退出码 | 符号 | 含义 |
|--------|------|------|
| 64 | `EX_USAGE` | 命令用法错误(如 `CHANDLER_RUNTIME` 非法值) |
| 65 | `EX_DATAERR` | 数据格式错误(如 lock 文件损坏) |
| 70 | `EX_CANTCREAT` | 安装损坏(如 run.sps 缺失) |
| 77 | `EX_NOPERM` | 权限不足 |
| 127 | `EX_NOTFOUND` | 找不到 runtime |

## 9. run.sps 位置

| 模式 | 路径 |
|------|------|
| install | `<prefix>/.chandler/<name>/run.sps` |
| pack | `<pack-root>/<name>/<version>/.chandler/run.sps` |

## 10. 启动器生成位置

| 模式 | 生成触发 | 实现位置 |
|------|---------|---------|
| install | `cmd-install` | `commands.ss:write-app-launcher!` |
| pack | `cmd-pack` | `pack.ss:generate-launchers` |

详见 [11-cli.md](11-cli.md) 的 `cmd-install` / `cmd-pack` 流水线。

## 11. Windows 特殊处理

### 11.1 路径约定

| 平台 | 用户 bin 目录 |
|------|--------------|
| POSIX | `~/.local/bin/` |
| Windows | `%LOCALAPPDATA%\chez\bin\` |

### 11.2 PowerShell 执行策略

Windows 启动器是 `.ps1` 文件。若报错「running scripts is disabled」:

```powershell
# 一次性方案(当前用户)
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# 或本次运行绕过
pwsh -ExecutionPolicy Bypass -File <app>.ps1
```

启动器头部的 `#!/usr/bin/env pwsh` 确保 POSIX 系统下用 pwsh(如已安装),Windows 下用默认 PowerShell。
